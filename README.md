# AiJudge
建立高品質的判決資料庫模型-以基隆地院毒品案件為例

## API(?
* https://opendata.judicial.gov.tw/dataset/detail?datasetId=ID
> ID = 51427-51788

* https://opendata.judicial.gov.tw/api/FilesetLists/ID/file
> ID = 63694-64055

> 主要欄位說明: ID(案號)、JYEAR(年度)、JCASE(字別)、JNO(號碼)、JDATE(裁判日期)、JTITLE(案由)、JFULL(全文)、JPDF(裁判書PDF檔下載連結)
